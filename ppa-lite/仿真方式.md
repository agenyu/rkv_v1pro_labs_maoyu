# PPA-Lite 仿真方式

## 1 环境要求

- QuestaSim 2021.1：`vlog`、`vsim`、`vcover` 已加入 `PATH`
- GNU Make 4.x
- MSYS2 `sh.exe`

QuestaSim 无法在包含中文的工程路径下稳定创建 `work` 库。因此不要直接在当前
桌面路径运行；先把 `ppa-lite` 复制到纯英文路径。

## 2 复制到纯英文路径

在 PowerShell 中执行：

```powershell
$src = "C:\Users\maoyu\Desktop\实验\rkv_v1pro_labs\ppa-lite"
$dst = "C:\ppa_lite_run_20261102"
Copy-Item -LiteralPath $src -Destination $dst -Recurse
Set-Location $dst
```

确认当前路径：

```powershell
Get-Location
```

期望输出为 `C:\ppa_lite_run_20261102` 一类纯英文路径。

## 3 快速冒烟

```powershell
make smoke
```

该命令编译 PPA-Lite，并运行：

- `lab1_defaults_test`
- `lab3_e2e_test`

日志应包含：

```text
[TEST START] ... seed=1
[TEST PASS] ...
Errors: 0, Warnings: 0
```

## 4 运行单个测试

```powershell
make run TESTNAME=lab3_e2e_test SEED=7
```

指定测试和 seed 后，日志文件名称为：

```text
run_lab3_e2e_test_7.log
```

可用测试名称：

```text
lab1_defaults_test
lab1_pkt_mem_test
lab1_pslverr_test
lab2_valid_test
lab2_errors_test
lab3_e2e_test
lab3_two_frames_test
lab3_busy_protect_test
lab3_irq_test
lab3_reset_recovery_test
lab4_random_test
lab4_error_mix_test
lab4_closure_test
```

## 5 正式回归

```powershell
make regress SEEDS="1 2 3"
```

正式回归为 13 个测试 × 3 个 seed，共 39 次仿真。每次测试必须满足：

```text
[TEST PASS]
Errors: 0, Warnings: 0
```

对应日志位于工程根目录，例如：

```text
run_lab4_closure_test_3.log
```

## 6 覆盖率采集与报告

```powershell
make cov
make mergecov
make report
```

也可以直接执行：

```powershell
make report
```

生成的覆盖率证据：

```text
cov/merged.ucdb
cov/dut_merged.ucdb
cov/html_dut/index.html
cov/html_functional/index.html
cov/dut_summary.txt
cov/functional.txt
```

其中：

- `dut_merged.ucdb` 只统计 `/tb/dut` 下的 DUT 五类代码覆盖率。
- `merged.ucdb` 包含功能覆盖组，用于查看 `cg_ppa`。
- 当前最终结果：功能覆盖 `100%`；statement `96.93%`、branch `95.14%`、
  condition `96.42%`、FSM `100%`、toggle `92.60%`。

## 7 查看覆盖率

用浏览器打开：

```text
cov/html_dut/index.html
cov/html_functional/index.html
```

或者在 QuestaSim 中打开：

```text
cov/dut_merged.ucdb
```

现场验收时应直接打开原始 UCDB 或 HTML 报告，不能只展示截图。

## 8 清理

```powershell
make clean
```

该命令只删除工程生成的 `work`、`cov`、日志和波形文件，不修改
`rtl/`、`tb/`、测试计划和实验报告。
